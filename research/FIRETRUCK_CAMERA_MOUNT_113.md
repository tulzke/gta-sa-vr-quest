# 113 — Начало координат камеры у водомёта

17.11.2026, после первой проверки MVP в Quest: пользователь подтвердил
горизонтальное отражение видео и сообщил о мерцающей геометрии перед камерой.
Смещения камеры должны настраиваться отдельно от источника воды.

Начало координат найдено в пользовательской модели `firetruk.dff`:

- Узел `misc_a`, цепочка `misc_a → chassis → chassis_dummy → firetruk`.
- Координаты оси относительно машины: **(0, 1.6391143799, 1.6495790482) м**.
- Оси в исходном положении: X вправо, Y вперёд, Z вверх.
- SHA256 извлечённого DFF с секторным дополнением:
  `9efa4603bfa245024629f74b87c5ebcbbf349e361e7c02e4c47c09eae068f4f2`.

Расчёт воспроизводится командой
`python tools/inspect-firetruck-nozzle.py path/to/firetruk.dff`.
Она читает только таблицу кадров, складывает преобразования всех родителей
и проверяет совпадение с fallback в моде. Игровой DFF не добавлен в Git.

Retail ABI: `CAutomobile + 0x8a0` содержит кадр водомёта. Native `PreRender`
в `0x6af294` читает pitch из `+0xb84`, устанавливает вращение X с reset=true,
затем читает yaw из `+0xb80` и добавляет Z. Эти инструкции проверяются
`tools/test-water-monitor-retail.py`. Положение LTM этого же кадра используется
штатным `FireTruckControl` перед созданием воды. Поэтому источник координат
доступен без подбора на глаз; runtime читает LTM узла, а вычисленная координата
служит проверенным запасным вариантом.

Калибровка камеры:

- `WaterMonitorCamera.407.0..2`: вправо/вперёд/вверх, сантиметры относительно
  оси сопла. Смещение вращается вместе с фактическим водомётом.
- `.3..5`: pitch/yaw/roll, градусы относительно нулевых осей крепления.
  Оптический поворот добавляется к мгновенному желаемому направлению пульта;
  камера не наследует задержку сервопривода. При ненулевых углах прицел цели
  проецируется в настроенный вид, как и кружок фактического направления.
- По умолчанию `(35, 0, 30) см`, углы нулевые. Локальные габариты геометрии
  сопла по X около ±21,5 см, по Z −15,2…+16,7 см: камера вынесена за них.
  Прежние `(13, 0, 15) см` попадали внутрь этих габаритов.
- В VR-меню транспорта у Firetruck доступны шесть параметров и сброс.
  Выбранный параметр включает экран для предпросмотра в иммерсивном режиме;
  ввод воды заблокирован и требует нового хвата после меню.

Точный источник мерцания ещё не подтверждён в Quest. Собственная машина
по-прежнему исключается из списка дополнительной камеры; перенос камеры
устраняет её исходное пересечение с областью сопла.

Сетка экрана имеет U, возрастающую с локальной X. Удалено лишнее `1-U`,
перенесённое из прицелов оружия: для этой UV оно отражало изображение.
Остальные камеры не менялись. Регрессионный тест проверяет ориентацию UV
на настоящей runtime-сетке, позу камеры и восстановление рендер-состояний.

Вызов `CWaterCannons::UpdateOne` и вычисление его исходных позиции/скорости
не используют настройки камеры. Вода создаётся прежним native путём:
LTM сопла + фактическое направление × 1,2 м + поправка движения точки машины.
Перенос или поворот камеры не перемещает воду и не перенастраивает сервопривод.
