# 32 — ABI доступности нитро и дебаг-предпросмотр

Дата: 16.11.2026. Исследование целевой Android ARM64 2.11.311, без изменений
игрового кода, запуска игры или установки на Quest.

## Результат

Для вопроса «предусмотрена ли на этой модели установка нитро?» есть штатный
экспорт `CVehicleModelInfo::IsUpgradeAvailable(VehicleUpgradePosn)`, слот нитро —
`15` (`UPGRADE_NITRO`). Проверка читает данные модели и не зависит от наличия
установленного комплекта, количества зарядов и процесса восстановления.

```cpp
using IsUpgradeAvailableFn = bool (*)(void* vehicleModelInfo, std::int32_t slot);
// vehicleModelInfo — CVehicleModelInfo*, не CVehicle*.
const bool supportsNitro = IsUpgradeAvailable(vehicleModelInfo, 15);
```

| Назначение | Экспорт | RVA в исследованном ELF |
| --- | --- | --- |
| Доступность апгрейда модели | `_ZN17CVehicleModelInfo18IsUpgradeAvailableE18VehicleUpgradePosn` | `0x5354C4`, размер `0x1C` |
| Установленный апгрейд экземпляра | `_ZN8CVehicle10GetUpgradeEi` | `0x6E4A24`, размер `0xD8` |
| Установка флагов апгрейда, с побочными эффектами | `_ZN8CVehicle22SetVehicleUpgradeFlagsEiiRi` | `0x6E46E4` |
| Штатное управление нитро, с побочными эффектами | `_ZN11CAutomobile14NitrousControlEa` | `0x6AA3E0` |
| Штатный запрос кнопки нитро | `_ZN4CPad13GetNitroFiredEv` | `0x49D844` |

RVA указаны для сверки, а не как абсолютные адреса процесса. Для подключения
использовать существующий механизм разрешения экспортов в `Symbols.cpp`.

## Проверка на целевой библиотеке

Источник: `build/quest-deploy/template/split_config.arm64_v8a.apk`, запись
`lib/arm64-v8a/libGame.so`. Сравнение подтвердило полное совпадение с локальной
копией `build/vehicle-lift-lever/retail.so`, по которой выполнено дизассемблирование.

- ELF64 little-endian AArch64, 8 943 088 байт.
- SHA-256: `4c6a7445e30b27afdda781302e4db9bac89c28fc1181b68b1eef16f84d6a282e`.
- Экспорт и размер получены из `.dynsym`; инструкции проверены побайтно по
  отображению виртуальных адресов через ELF PT_LOAD.

Полное тело `IsUpgradeAvailable`:

```asm
5354c4: f9404808  ldr x8, [x0, #0x90]
5354c8: 2a0103e9  mov w9, w1
5354cc: 8b091508  add x8, x8, x9, lsl #5
5354d0: b940d108  ldr w8, [x8, #0xd0]
5354d4: 2a2803e8  mvn w8, w8
5354d8: 531f7d00  lsr w0, w8, #31
5354dc: d65f03c0  ret
```

ABI вызова: `x0` — указатель модели (`this`), `w1` — 32-битный номер слота,
`w0` — результат 0/1. Побочных эффектов и записей в память нет.

Смысл функции: из `modelInfo + 0x90` читается указатель структуры модели,
затем проверяется неотрицательность знакового 32-битного parent component ID
по адресу `structure + 0xD0 + slot * 0x20`. Для слота 15 это `structure + 0x2B0`.

Дополнительное подтверждение именно нитро в целевом ELF:
`CVehicle::SetVehicleUpgradeFlags` выделяет ветку `slot == 15` при `0x6E46F0`;
она вызывает `CAutomobile::NitrousControl` при `0x6E47B4`, после чего читает
`modelInfo + 0x90`, `structure + 0x2B0` и проверяет знаковый бит при
`0x6E47C8…0x6E47D0`. Это тот же признак доступности слота.

**Не вызывать `SetVehicleUpgradeFlags` как предикат:** до проверки признака
она уже вызывает `NitrousControl`, который при положительном аргументе меняет
число зарядов, состояние нитро и эффекты. Для дебаг-просмотра достаточно
чистого `IsUpgradeAvailable`.

## Проверка установленного оборудования — отдельно

`CVehicle::GetUpgrade(int)` принимает `CVehicle*` и номер слота. В ветке 15,
если не найден соответствующий atomic, при `0x6E4AB8…0x6E4AD0` проверяется бит 3
байта `vehicle + 0x4BA`. При отсутствии возвращается `-1`, при наличии — ID
из глобальной `MI_NITRO_BOTTLE_SMALL` (общий признак наличия, не точный размер
установленного комплекта). Этот путь не читает текущий остаток заряда.

Следовательно, `GetUpgrade(vehicle, 15) != -1` подходит для проверки наличия
оборудования, но **не заменяет совместимость модели** для дебаг-меню. Его
полное тело вначале обходит atomics текущего clump: вызывать только для валидной
загруженной машины с clump, на игровом потоке.

## Правило размещения

| Совместимость модели | Нитро установлено | Дебаг-пункт и предпросмотр | Обычный физический рычаг |
| --- | --- | --- | --- |
| Да | Нет | Есть, доступна настройка положения | Скрыт |
| Да | Да | Есть | Есть при обычных условиях IMMERSIVE/водитель/FIRST |
| Нет | Нет | Отсутствуют | Скрыт |

Дебаг-предпросмотр не устанавливает комплект, не выдаёт запас и не вызывает
реальную подачу. На совместимой машине без комплекта он использует только
визуальные OFF/ON и тестовый процент шкалы. Скриптовая/читовая принудительная
выдача оборудования на неподдерживаемую модель не меняет чистый признак
доступности апгрейда для дебаг-размещения.

Перед вызовом нужны валидный автомобиль, допустимый индекс модели, существующий
`CModelInfo::ms_modelInfoPtrs[modelId]`, правильный тип model info и ненулевой
указатель структуры по `+0x90`. Экспорт не проверяет указатели и границы слота;
передавать только фиксированный слот 15. Уже имеющийся в проекте
`g.CModelInfo_ms_modelInfoPtrs` позволяет получить модель без нового поиска.
Незагруженную модель считать временно недоступной, не кэшировать это как
постоянную несовместимость. При отсутствии экспорта скрывать недоступную настройку.

Это признак поддержки апгрейда у загруженной геометрии модели; он не проверяет
место водителя, здоровье двигателя, игровые запреты и условия фактического
впрыска. Эти условия проверяются отдельно.

## Внешнее сопоставление и границы проверки

[Plugin-SDK CVehicleModelInfo.h](https://github.com/DK22Pac/plugin-sdk/blob/master/plugin_sa/game_sa/CVehicleModelInfo.h)
содержит enum `VehicleUpgradePosn` с `UPGRADE_NITRO == 15` и объявление функции.
[gta-reversed VehicleModelInfo.cpp](https://github.com/gta-reversed/gta-reversed/blob/master/source/game_sa/Models/VehicleModelInfo.cpp)
описывает тот же смысл проверки parent component ID. Это вспомогательное
сопоставление имён; адреса, смещения и инструкции выше подтверждены Android ELF,
а не перенесены из PC-заголовков.

Временный проверяющий скрипт и дизассемблирование сохранены в игнорируемом
`build/nitro-abi-research/`. Выполнена статическая проверка целевого APK;
матрица реальных автомобилей и поведение предпросмотра в Quest ещё не проверены.
