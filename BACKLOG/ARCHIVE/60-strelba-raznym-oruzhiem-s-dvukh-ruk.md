## Стрельба разным оружием с двух рук

**Закрыта 15 ноября 2026 года по подтверждению пользователя: «Всё норм. можно закрывать».** Реализация принята после сверки с текущим кодом. Приведённые ниже незакрытые пункты сохранены как исходная матрица проверок: отдельное прохождение каждого сценария пользователем не заявлялось и не блокирует принятое закрытие.

Сделать возможной одновременную стрельбу разным оружием в каждой руке. Сейчас лазерный прицел перескакивает с одного оружия на другое; обеспечить независимое прицеливание для каждой руки. Проверить прицелы и стрельбу обеими руками в Quest.

Дополнение: у каждого из двух оружий должны быть собственные счётчик патронов, магазин и продолжительность перезарядки. Перезарядка левого оружия не мешает стрельбе правым, и наоборот.

### Реализация 10.11.2026

- [x] Оба физических спуска обрабатываются за один игровой кадр, с отдельными защёлками и темпом огня. Контекст активного слота восстанавливается после каждого выстрела.
- [x] Каждая рука использует свой тип оружия, калибровку и луч попадания. В стереокадр передаются два независимых лазера.
- [x] Расход патронов и перезарядка сохраняются в собственном CWeapon каждого инвентарного слота; счётчик на каждом оружии читает его боезапас. Перекладывание и убирание оружия не сбрасывают его таймер.
- [x] Вместимость магазина учитывает один физический ствол: удвоенная ёмкость штатного twin-pistol режима на высоком навыке делится пополам. Патроны при этом не удаляются из общего остатка данного оружия.
- [x] Продолжительность берётся из штатного GetWeaponReloadTime для этого типа/навыка без twin-pistol сокращения и независимо от общей анимации CJ. Завершение перезарядки одного ствола не меняет магазин другого.
- [x] Автотесты: 29 проверок производственного цикла двух рук и 56 проверок маршрутизации миссионного оружия. Android-сборка и установка штатным deploy-quest.ps1.
- [ ] Проверить в Quest одновременный огонь в разные стороны, совпадение обоих лазеров с попаданиями, счётчики на обоих оружиях и стрельбу каждой рукой во время перезарядки другой.
- [ ] Проверить в Quest разные типы оружия/навыки, неполный остаток патронов, передачу и убирание во время перезарядки, одиночный спуск, двухручный хват и миссионные/автомобильные сценарии.

### Дополнение: одинаковое оружие в парных холстерах

- [x] Колесо каждого поясного холстера показывает также оружие соседнего. При недостаточном навыке или отсутствии штатного парного режима пункт красный и не меняет раскладку при выборе. Автомобильное ограничение применяется дополнительно.
- [x] На уровне HITMAN и при наличии twin-pistol флага в текущих данных оружия можно оставить основной ствол в одном холстере и назначить второй в соседний. Поддержаны штатные парные типы: пистолет, обрез, Micro SMG и Tec-9.
- [x] Второй экземпляр хранит отдельный магазин/таймер, получает собственную модель, луч, отдачу и счётчик. В штатный инвентарь не добавляются ложные слоты: на время синхронного выстрела подставляется состояние нужного экземпляра, затем восстанавливается основное.
- [x] Оба одинаковых ствола расходуют исходный общий запас патронов. Счётчик каждого показывает его магазин и общий свободный резерв, исключая патроны в магазине другого. Создание/удаление пары не увеличивает и не уменьшает общий боезапас, который сохраняется штатной игрой.
- [x] Парная раскладка сохраняется в настройках. После удаления основного холстера оставшийся экземпляр становится основным; при потере навыка второй нельзя взять. Перезарядка второго завершается по своему таймеру и в холстере.
- [x] 51 проверка цикла стрельбы, в том числе одинаковые пистолеты, независимые лучи/магазины/таймеры и отсутствие дублирования патронов; проверки настроек/колеса, навыка, транспорта, удаления пары, отдачи и миссионной маршрутизации.
- [ ] В Quest проверить красный пункт при низком навыке, выбор пары на HITMAN, сохранение раскладки, одновременную стрельбу двумя одинаковыми стволами, отдельные счётчики/перезарядку, передачу и убирание каждого экземпляра.

### Дополнение: два колеса одновременно

- [x] Каждая рука имеет собственное состояние колеса, выбранный сектор и отмену. Оба колеса могут быть открыты одновременно у разных холстеров; один холстер не редактируется двумя руками одновременно.
- [x] Оба колеса публикуются одним снимком и отображаются в одном стереокадре, с отдельными областями атласа иконок и счётчиками патронов.
- [x] Выбор проверяет актуальную раскладку: если обе руки одновременно выбрали ранее свободное оружие, второй экземпляр назначается только при достаточном навыке. Уже открытое второе колесо обновляет доступность/красную подсветку после выбора первой рукой.
- [x] Автотесты производственного блока: одновременное открытие и публикация, выбор одной рукой, независимая отмена, два одинаковых выбора, запрет обхода навыка, обновление красной подсветки, общая блокировка и защита от редактирования одного холстера двумя руками. Проверены непересекающиеся области иконок обеих рук.
- [ ] В Quest проверить удобство одновременного выбора, видимость иконок/счётчиков, разные сектора и независимое закрытие обоих колёс.
