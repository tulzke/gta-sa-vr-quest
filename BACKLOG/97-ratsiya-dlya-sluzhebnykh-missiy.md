## Рация для запуска служебных миссий в транспорте [В РАБОТЕ]

Добавить физическую рацию в служебный транспорт. Взаимодействие с ней запускает соответствующую штатную миссию: полицейского, медика, пожарного и другие доступные для данного транспорта задания.

При реализации определить поддерживаемые модели и штатные условия запуска, конкретный жест взаимодействия и размещение рации. Не запускать миссию от случайного касания или удержанного ввода при посадке. Использовать игровую логику доступности задания; наличие рации не должно обходить миссионные ограничения.

Проверить в Quest запуск каждого поддерживаемого типа миссии, отмену повторным взаимодействием при уже активном служебном задании, недоступность запуска, смену транспорта и возвращение после завершения миссии. Проверить досягаемость рации и отсутствие конфликтов с рулём, оружием, радио и другими элементами кабины. Пользователь уточнил: через рацию необходима и отмена служебного задания; чужие сюжетные задания не отменять.

### Игровая реализация — 16.11.2026

Реализованы ручная рация/держатель, общий материал цветной накладки, отдельный PTT, Action HandleRadio, владение одной рукой и возврат за 180 мс. Новый grip захватывает предмет; после отпускания триггера новое нажатие запускает или отменяет соответствующее штатное задание. Удержание не повторяет действие. Триггер занятой руки не управляет педалью, не стреляет и не отвечает на телефон/диалог; после отпускания рации с зажатым триггером педаль ждёт его отпускания. Другой рукой можно продолжать рулить и управлять её педалью.

Первая область: Ambulance 416 (белый), Firetruck 407 (красный), наземные полицейские модели 427/432/490/523/528/596/597/598/599/601 (синий). Авиация, лодки, такси и телефон задачи 98 пока не подключены. В Vehicle Debug триггером возле рации можно переместить/повернуть держатель; ServiceRadioPose сохраняется отдельно для модели. Начальные положения требуют проверки в кабинах.

Использован штатный диспетчер mainv1.scm: widget 70 для запуска, widget 72 для отмены. Globals и LOAD_AND_LAUNCH_MISSION не подменяются. Активность читается по mission threads COPCAR/AMBULAN/FIRETRU; запрос привязан к типу/экземпляру задания и SeatKey с поколением vehicle pool. Смена/выход из машины, загрузка, меню/катсцена, чужое владение рукой, потеря трекинга/его эпохи сбрасывают запрос и хват. Срок ожидания опроса — 250 мс; единичный импульс 120 мс учитывает штатный latch отмены COPCAR. Чужая сюжетная миссия не получает отмену. Совместимость версии проверяется по инструкциям диспетчера.
