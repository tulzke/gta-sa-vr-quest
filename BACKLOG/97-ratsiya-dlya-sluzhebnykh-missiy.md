## Рация для запуска служебных миссий в транспорте [В РАБОТЕ]

Добавить физическую рацию в служебный транспорт. Взаимодействие с ней запускает соответствующую штатную миссию: полицейского, медика, пожарного и другие доступные для данного транспорта задания.

При реализации определить поддерживаемые модели и штатные условия запуска, конкретный жест взаимодействия и размещение рации. Не запускать миссию от случайного касания или удержанного ввода при посадке. Использовать игровую логику доступности задания; наличие рации не должно обходить миссионные ограничения.

Проверить в Quest запуск каждого поддерживаемого типа миссии, отмену повторным взаимодействием при уже активном служебном задании, недоступность запуска, смену транспорта и возвращение после завершения миссии. Проверить досягаемость рации и отсутствие конфликтов с рулём, оружием, радио и другими элементами кабины. Пользователь уточнил: через рацию необходима и отмена служебного задания; чужие сюжетные задания не отменять.

Отдельной задачи на такую рацию не найдено. Это отдельное устройство от крутилки музыкального радио из [задачи 30](ARCHIVE/30-fizicheskoe-upravlenie-radio.md). Связанный вариант для машины сутенёра описан в [задаче 98](98-telefon-v-mashine-sutenera.md).

### Дизайн-ревью — 16.11.2026

Подготовлено [предложение по форме, взаимодействию и интеграции](../research/SERVICE_RADIO_REVIEW_97.md). Это проект решения для обсуждения; пользователь ещё не утвердил механику и внешний вид. Код и игровые ассеты не изменялись.

Рекомендуемый вариант: автомобильная рация с тангентой на держателе; новый grip снимает тангенту, новое нажатие триггера этой руки отправляет один штатный запрос запуска либо отмены активного служебного задания. Подносить ко рту не обязательно. Отпускание возвращает тангенту на держатель без игрового действия. По уточнению пользователя триггер рации имеет приоритет над газом и тормозом: владеющая тангентой рука не управляет своей педалью.

До реализации подтвердить штатный канал запуска и состояния каждой поддержанной миссии на пользовательской Android-версии. Найденный общий мост кнопок миссий сам по себе не подтверждает канал служебных заданий. Модели, точное размещение, размеры и пороги пока являются кандидатами для проверки. Сохранены все исходные требования и проверки выше.

По запросу пользователя подготовлена концептуальная визуализация нейтрального исполнения: тёмно-серый корпус, съёмная тангента со светло-серой боковой кнопкой, витой провод и держатель, без символики служб и брендов. Это изображение для обсуждения формы; Blender-модель и игровые ассеты пока не создавались, внешний вид ещё не утверждён.
