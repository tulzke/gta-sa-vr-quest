## Телефон в машине сутенёра для запуска миссии

Добавить физический телефон в машину сутенёра как вариант взаимодействия для запуска соответствующей штатной миссии. Использовать телефон вместо служебной рации из [задачи 97](97-ratsiya-dlya-sluzhebnykh-missiy.md).

При реализации определить подходящий транспорт, размещение и жест взаимодействия с телефоном. Соблюдать штатные условия запуска миссии; исключить случайный запуск при посадке и повторный запуск уже активного задания.

Проверить в Quest наличие телефона только на подходящем транспорте, запуск миссии, её недоступность, повторное взаимодействие и переходы между машинами. Проверить досягаемость и отсутствие конфликтов с остальными предметами кабины.

Отдельной задачи на этот телефон не найдено. Отложенный телефонный интерфейс из [задачи 76](ARCHIVE/76-chasy-s-kartoy-i-telefonnye-zvonki.md) посвящён сюжетным звонкам и не заменяет этот сценарий.
