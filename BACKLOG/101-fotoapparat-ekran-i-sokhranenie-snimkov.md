## Работающий фотоаппарат с экраном и сохранением снимков через API

Сделать игровой фотоаппарат работающим в VR. Добавить экран по аналогии с экраном на базуке, хват основной руки как у пистолета и опору второй руки под объективом. Съёмка должна соответствовать направлению фотоаппарата и изображению на его экране.

Сохранять фотографии через доступный API. При реализации исследовать наличие универсального API; если его нет, проверять доступность API конкретной системы, шлема или среды и выбирать поддерживаемый способ. Не предполагать наличие платформенного API без проверки. При недоступном сохранении или ошибке сообщать об этом, не показывая ложный успех.

Проверить в Quest экран, кадрирование, съёмку и фактическое сохранение снимка, повторные снимки, хват каждой рукой и поддержку под объективом. Проверить доступность API, необходимые разрешения, отказ в доступе и неподдерживаемую среду. Сохранить штатные игровые события фотографирования, где они нужны миссиям.

Отдельной задачи на фотоаппарат не найдено. Для хвата учесть реализацию [задачи 20](ARCHIVE/20-dvuruchnyy-khvat-odnoruchnogo-oruzhiya.md); выбор API и совместимость исследовать при реализации.
