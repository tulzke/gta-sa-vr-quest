# Модель радио

`Radio.blend` — исходная модель. Объекты `Подложка` и `Крутилка` используют две упакованные PNG-текстуры. Экспортированные ресурсы лежат в `runtime/`.

В `base.uxrh` и `knob.uxrh` сохранены треугольники, UV и нормали после применения модификаторов. У обоих мешей общий ноль — origin крутилки в исходной сцене; ось вращения проходит по Blender Z. Координаты и размеры сохранены в единицах сцены Blender, масштаб для игры нужно задать при подключении. `manifest.json` содержит размеры текстур и исходное положение точки вращения. `base.png` и `knob.png` — извлечённые из файла упакованные текстуры.

Формат UXRH изначально предназначен для рук с четырьмя позами. Для статических деталей четыре набора координат и нормалей одинаковы. Меши и текстуры встроены в нативную библиотеку; в игре основание неподвижно, а крутилка вращается вокруг общего origin. Исходный масштаб умножается на 0,1, размер основания — около 8 см. Размер, направление текстур и хват нужно проверить в Quest.

Для повторного экспорта из корня репозитория:

```powershell
blender -b assets/radio/Radio.blend --python tools/export_radio_assets.py -- assets/radio/runtime
```
